# Ежедневная работа

[К README](../../README.ru.md) | [English](../usage.md)

## Запуск и завершение

Подключите основной VPN на Mac, если он нужен, затем откройте Lazylead VPN и
выберите `Start Lima (Direct)`. Если VM уже работает, команда проверит её сеть.
Состояние Connected означает, что проверка default route VM прошла; оно не
заменяет отдельную проверку системных маршрутов или доступности каждого сайта.

`Quit Lazylead VPN` закрывает только интерфейс приложения. `Stop Lima`
останавливает VM, включая Transmission. Пока VM выключена, DNS-правила и
выбранные маршруты остаются на Mac. Для возврата к обычной сети используйте
[отключение правил](troubleshooting.md#отключение-правил).

После изменения правил перезапустите браузер, чтобы закрыть старые соединения
и сбросить его DNS-кэш. На проверенном Mac Brave 1.96.60 с Secure DNS «текущий
поставщик ОС» учитывал системное правило; отдельный DoH-провайдер может его обходить.

## Как посмотреть трафик через Lima

Выберите `Traffic & Routes…` в меню приложения или нажмите одноимённую кнопку
в Settings. При первом запуске новой функции окно открывается автоматически.
Оно читает установленные DNS-правила, снимок Yandex Cloud, состояние VM и таблицу
маршрутов macOS, не меняя сетевые настройки.

Сводка отдельно показывает настроенные домены со всеми поддоменами, диапазоны
Yandex Cloud, Transmission внутри VM и основной маршрут Mac. В таблице — только
пригодные IPv4-маршруты со шлюзом на настроенный IP Lima. `Global` означает,
что маршрут не ограничен одним интерфейсом, а не что весь интернет идёт через Lima.
Маршруты, ограниченные интерфейсом, отмечены отдельно.

Поиск принимает IP, CIDR-префикс или интерфейс. Для IP находится также покрывающая
подсеть: например, `51.250.33.235` найдёт `51.250.0.0/17`. `Copy routes` копирует
отфильтрованный список. `Refresh` обновляет данные в фоне; рядом показано время снимка.

Таблица описывает конфигурацию и установленные маршруты; это не проверка
доступности сайтов. Фактический путь зависит также от состояния VM, собственного
DNS приложения, более специфичных маршрутов и общих IP. Префиксов в снимке может
быть больше, чем установленных маршрутов: пересекающиеся префиксы используют
общий маршрут. По IP-таблице нельзя восстановить доменные имена, поэтому отдельные
адреса не подписываются как подтверждённые домены.

## Счётчики трафика

Панель **Measured traffic** в `Traffic & Routes…` показывает входящий и исходящий
объём и текущую скорость в режиме Direct. Сбор начинается при запуске приложения
в меню и продолжается при закрытом окне примерно раз в пять секунд, пока Mac
не спит. Первый успешный снимок — нулевая точка: старый трафик в итог не включается.

- **Lima uplink** — байты интерфейса `direct0`: Transmission, приложения VM,
  пересылаемый трафик Mac, служебные заголовки и локальный сетевой трафик.
- **Mac ↔ Lima link** — байты интерфейса VM с настроенным адресом шлюза.
  Направления показаны со стороны Mac: received — доставлено на Mac.
  Сюда входят локальный DNS и другой трафик линии. Этот объём пересекается
  с uplink: **строки нельзя складывать**. Разбивки по сайтам или приложениям нет.

Это не счётчик Pepper VPN и не биллинг провайдера. Считаются байты интерфейсов
разных протоколов, независимо от таблицы IPv4-маршрутов. Для сбора приложение
не скачивает данные из интернета и не меняет маршруты.

Начало учёта и время последнего снимка показаны в панели. История хранится
отдельно для каждой VM, шлюза и режима в
`~/Library/Application Support/Lazylead VPN/Traffic/` и сохраняется между запусками.
После повторного открытия приложения прирост за время его отсутствия учитывается,
если интерфейсы VM сохранились. Перезапуски определяются по boot ID и индексу
интерфейса: байты нового интерфейса добавляются, а предупреждение отмечает
возможный пропуск трафика перед незамеченным перезапуском. После долгого перерыва
текущая скорость не вычисляется.

Если VM остановлена или недоступна либо её единственный IPv4 default route
не использует `direct0`, панель сохраняет итог, показывает время последнего
снимка и сообщает о недоступности данных вместо нулевой скорости. Режим
Check Point сохранён; в нём явно указана недоступность учёта трафика.
Для счётчиков не нужны обновление системного помощника и пароль администратора.

## Transmission

Откройте [Web UI](http://127.0.0.1:9092/transmission/web/) при работающей VM.
Добавляйте торренты в Web UI; скачанные файлы появятся в `~/Downloads` на Mac.
Очередь и настройки сохраняются внутри VM между её запусками. Не удаляйте VM,
если хотите сохранить её состояние.

Проверить службу, заменив имя VM своим:

```bash
limactl shell --workdir / lazylead-vpn systemctl status lazylead-transmission.service
```

## Автозапуск приложения

```bash
./scripts/install_launch_agent.sh '/Applications/Lazylead VPN.app'
```

Это запускает интерфейс приложения после входа в macOS. Для запуска VM нажмите
`Start Lima (Direct)` — этот LaunchAgent сам не выполняет Connect.
Отключение автозапуска:

```bash
launchctl bootout "gui/$(id -u)/io.lazylead.vpn.autostart"
launchctl disable "gui/$(id -u)/io.lazylead.vpn.autostart"
```

## Обновление адресов Yandex Cloud

```bash
python3 scripts/collect_yandex_cloud_routes.py --output build/direct-network
sudo ./scripts/install_direct_routes.sh
```

DNS-служба для `.ru`/`.рф` изучает новые адреса по запросам автоматически.
Для остальных зон Yandex Cloud используется отдельный снимок префиксов.
